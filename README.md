# fineprint

A question-answering service over the official U.S. government handbook "Medicare & You 2026",
which answers in plain language and cites the handbook page it used. It is a portfolio project
about production RAG engineering: hybrid retrieval, a verified golden set, per-call observability,
LLM-as-judge evaluation, and an eval gate in CI.

## Why this project exists

Most retrieval demos stop at "it answered my question". This one is built around the harder
question: how good is the retrieval, and how would you know? The engineering is the subject.

- Hybrid retrieval — lexical search and vector similarity, fused with reciprocal rank fusion —
  rather than vector search alone.
- A golden set of questions a beneficiary or their adult child would actually ask, each with an
  expected answer and expected source pages taken from the PDF rather than guessed.
- Observability on every LLM and tool call, with cost and latency.
- An LLM judge calibrated against hand labels instead of trusted on faith.
- An eval gate in CI that blocks a pull request which makes answers worse.

Every part of the series ends with measured numbers, produced by a script and committed next to the
code that produced them.

## Scoreboard

The scoreboard is generated by a script in `evals/` from committed eval results, and is never
edited by hand. The same table closes every part of the series, with more columns filled in each
time: retrieval and manual-review columns in part 1, the four RAGAS metrics in part 2, cost and p95
latency in part 3, judge and adversarial pass rates in part 4. A cell with no measurement behind it
renders as `—`; it never carries a placeholder value.

## Run it

Prerequisites: [uv](https://docs.astral.sh/uv/) and Docker.

```bash
uv sync                                      # install dependencies
uv run python scripts/download_handbook.py   # fetch and verify the handbook into data/raw/
docker compose up -d --wait                  # Postgres 16 with pgvector on localhost:5432
uv run pytest
uv run python -m evals.verify_golden_set     # check every golden-set evidence quote against the PDF
```

The commands that ingest the handbook, run the service and produce the scoreboard arrive with
part 1.

## The corpus

"Medicare & You" is the handbook the Centers for Medicare & Medicaid Services mails to every
Medicare household each autumn: 128 pages covering enrollment, what each part covers, costs,
Medicare Advantage, Medigap, Part D, and where to get help. It is a U.S. government publication in
the public domain, and it is a good RAG test corpus precisely because it is awkward — two-column
comparison tables, cost figures that change every year, cross-references by page number, and a
five-page index.

The download script pins the file by sha256 and fetches it from the Internet Archive rather than
from medicare.gov. Two reasons:

- medicare.gov serves the handbook at a single unversioned URL, and that URL has served the 2027
  edition since September 2026. CMS keeps no public archive of prior-year handbooks.
- The 2026 edition exists in more than one printing, and they do not say the same thing. The
  September 2025 printing carries 2025 dollar amounts; the January 2026 printing carries the final
  2026 amounts. A cover that says "2026" is not enough. Pinning the hash is what makes an expected
  answer in the golden set mean something.

The PDF is not committed. `data/` is gitignored and the script fetches the file on demand,
verifying the hash before it writes anything into place.
